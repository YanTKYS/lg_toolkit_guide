このディレクトリは、`lg_toolkit_guide` を使った成果物の記入例・実証例をまとめる場所です。

## 1. examples/01_filename_sanitizer

- 設計書、README、チェックリスト、テストシナリオ、運用引継ぎ、手順書の書き方を示します。
- テンプレートを埋める際の最小例として参照してください。

## 2. examples/02_filename_sanitizer_context_result

`reference/guide_context.md` のみを参照して生成した実証成功例です。

- 参照方式: 同梱方式（外部URL未使用）
- 標準構成: `README.md` / `development_report.md` / `docs/` / `manuals/`
- 用途: guide_context単体参照時に、どの粒度で成果物が揃うかの確認

> 注: `02` は実証成果物の文書例です。実装コード（`src/`）は原則含めません。
