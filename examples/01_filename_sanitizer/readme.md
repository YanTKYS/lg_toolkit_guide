# ファイル名安全化ツール README（記入例）

## 1. 概要

入力したファイル名候補を、Windowsで安全に使える文字列へ整形する補助ツールです。

## 2. 目的

保存時エラーの予防と、庁内での命名ルール統一を支援します。

## 3. 対象利用者

一般職員、文書管理担当、庶務担当。

## 4. 利用環境

- OS: Windows 10/11
- ネットワーク: 庁内ネットワーク
- 必要ソフト: 標準ブラウザ
- 配置: IIS等の静的配布

## 5. できること

- 使用不可文字の除去/置換
- 末尾空白・末尾ピリオド除去
- 予約語の警告と候補名調整
- 複数行一括変換

## 6. できないこと

- 実ファイルの自動変更
- ネットワークドライブ上の一括リネーム
- 命名規則の業務判断自動化

## 7. 使い方

1. ツールを開く
2. ファイル名候補を入力（複数行可）
3. 「変換」を押す
4. 結果を確認し、必要に応じてコピー/保存する

## 8. 入力データ

- 文字列（1行1件）
- 文字コード: UTF-8想定

## 9. 出力データ

- 画面表示（元文字列 / 変換候補）
- コピー用テキスト

## 10. 個人情報の取扱い

- 個人情報入力を想定しない
- 入力値・結果を永続保存しない
- 外部送信しない

## 11. 外部ライブラリ

- 使用なし

## 12. 注意事項

- 変換結果は必ず利用者が確認してください。
- 本ツールはファイル名候補作成の補助であり、最終判断は利用者が行ってください。

## 13. 動作確認方法

- 正常系、異常系、再実行系を `test_scenarios.md` で確認
