# 利用者向け手順書（記入例）

## 1. このツールでできること

- ファイル名に使えない文字を、安全な名前に整えます。

## 2. このツールでできないこと

- 実際のファイル名を自動変更することはできません。

## 3. 使い方

1. ツールを開きます。
2. ファイル名候補を入力します。
3. 「変換」を押します。
4. 結果を確認し、必要ならコピーします。

## 4. よくあるエラー

- 入力が空です → 文字を入力してください。

## 5. 注意

- 結果は必ずご自身で確認してください。
- 個人情報を含む内容は入力しないでください。

## 6. 問い合わせ先

- 所管部署（例）
