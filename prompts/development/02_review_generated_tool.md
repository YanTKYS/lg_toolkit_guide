# 02_review_generated_tool.md

以下の条件で、生成済み内部ツール（コード + ドキュメント）をレビューしてください。

## 前提（必須参照）

- `docs/00_policy.md`
- `docs/01_ai_coding_rules.md`
- `docs/05_release_checklist.md`
- `docs/08_test_scenarios_template.md`
- `examples/01_filename_sanitizer/`

## レビュー観点（必須）

- `docs/00_policy.md` に反していないか
- `docs/01_ai_coding_rules.md` に反していないか
- 外部CDN、外部API、クラウド依存がないか
- 個人情報を保存・送信・ログ出力していないか
- 元ファイルを破壊しないか
- READMEが十分か
- エラー表示が分かりやすいか
- 再実行時に破綻しないか
- リリース前チェックとテストシナリオが埋まっているか
- `examples/01_filename_sanitizer` と同程度の説明粒度があるか

## 入力情報（この下を埋めて使用）

- レビュー対象ファイル一覧:
- 想定利用環境:
- 既知の懸念点:

## 出力形式（この順序を厳守）

1. 総評
2. 重大な問題
3. 軽微な問題
4. 不足しているドキュメント
5. 修正提案
6. リリース可否（可 / 条件付き可 / 不可）
7. 次に確認すべきこと

## 出力ルール

- 指摘は「対象ファイル」と「該当箇所」が分かるように書く。
- 重大な問題は、修正しない限りリリース不可とする。
- 修正提案は可能な限りそのまま反映できる文面で示す。
