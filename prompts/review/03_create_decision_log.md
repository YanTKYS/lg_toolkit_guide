# 03_create_decision_log.md - 方針逸脱レビュー判断ログ作成プロンプト

以下の情報をもとに、Vibe Codingにおける方針逸脱レビューの判断ログを作成してください。

## 目的

実装AIの提案、第三者レビュー、ユーザーの最終判断を後から振り返れる形で記録することです。

## 入力欄

### 論点

（ここに記入）

### 当初方針

（ここに記入）

### 実装AIの提案

（ここに記入）

### 第三者レビューの判定

（ここに記入）

### 最終判断

（ここに記入）

### 理由

（ここに記入）

### 実装AIへの指示

（ここに記入）

### 後続課題

（ここに記入）

## 出力形式

次の形式で、raw表示でも読みやすいMarkdownとして出力してください。

```markdown
## 判断ログ

### YYYY-MM-DD 論点名

- 論点:
- 当初方針:
- 実装AIの提案:
- 第三者レビューの判定:
- 最終判断:
- 理由:
- 実装AIへの指示:
- 後続課題:
```

## 注意事項

- 実装は行わないでください。
- 判断ログは、事実、判定、最終判断を分けて記録してください。
- 最終決定権はユーザーにあるため、第三者レビューの判定と最終判断が異なる場合も、そのまま記録してください。
- 未決事項がある場合は、後続課題に明記してください。
