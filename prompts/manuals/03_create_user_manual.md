# 03_create_user_manual.md

以下の条件で、**利用者向け手順書**を日本語で作成してください。

## 前提（必須）

- `guides/00_policy.md` と `guides/01_ai_coding_rules.md` を必ず前提にすること。
- 対象読者は一般職員であることを意識すること。
- 文章は短く、画面を見ながら操作できるようにすること。
- 専門用語を避け、必要なら言い換えを併記すること。
- 「できないこと」を必ず明記すること。

## 出力条件

- 見出しは分かりやすく短くする。
- 操作手順は番号付きで記載する。
- エラー時の対処は「まず何を確認するか」を先に示す。

## 手順書に必ず含める項目

1. ツール名
2. このツールでできること
3. このツールでできないこと
4. 利用対象者
5. 利用前に準備するもの
6. ツールの開き方
7. 基本操作
8. 入力方法
9. 実行方法
10. 結果の見方
11. コピー、保存、印刷の方法
12. よくあるエラー
13. エラー時の対応
14. 注意事項
15. 個人情報を扱う場合の注意
16. 問い合わせ先
17. 簡易FAQ

## 入力情報（この下を埋めて使う）

- ツール名:
- 対象利用者:
- 主な利用場面:
- 入力するもの:
- 出力されるもの:
- 問い合わせ先:

## 出力形式

- 見出し付きMarkdown
- A4で2〜4ページ程度を目安に簡潔にまとめる
- 最後に「最短操作手順（3〜5ステップ）」を付ける
