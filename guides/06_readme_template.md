# 06_readme_template.md - READMEテンプレート

READMEは履歴台帳ではなく、**現在このツールを使う人が必要な情報**を示す現行仕様書である。該当しない節は削除し、空の見出しを残さない。

```markdown
# ツール名

## 概要

- 何を支援するツールか:
- 対象利用者:

## 利用環境・開始方法

- 対応環境:
- 配置・起動方法:
- 必要な前提（該当時のみ）:

## できること

- 現在利用できる主な処理:

## 使い方

1.
2.
3.

## 入力と出力

- 入力:
- 出力:
- 元データ・保存データの扱い:

## 利用時の注意

- 利用者が結果を確認すべき点:
- 安全な利用判断に必要な対象外・制約（該当時のみ）:

## 問題が起きたとき

- 利用者が最初に確認すること:
- 問い合わせ先・伝える情報:

## 保守情報

- 現在のバージョン:
- 保守担当・範囲:
- 動作確認方法:
- 利用・保守判断に必要な既知の制限（該当時のみ）:
```

## 記載ルール

- 「できないこと」を網羅しない。対象外や制約は、誤利用防止や利用判断に必要なものだけを書く。
- 既知の制限も、利用者または保守者が回避・判断するために有用なものだけを書く。
- 通常利用を妨げ、解消可能な不具合はREADMEへ固定化する前に修正する。
- 更新履歴はREADMEへ積み上げず、必要ならGitHub Release、release notes、CHANGELOG等へ分離する。
- 外部依存、個人情報、一時ファイルなどは、そのツールで実際に利用判断へ影響する内容だけを書く。
- 実装変更後は、使い方、入出力、表示、前提条件、制限が現行動作と一致するか確認する。
