# 07_prompt_template.md - Vibe-coding用プロンプトテンプレート

## 使い方

プロンプトは案件固有情報に集中させる。恒久ルールは `guides/00_policy.md` と `guides/01_ai_coding_rules.md` を参照させ、本文へ再列挙しない。用途に応じてUI、README、テスト、配布などの追加ガイドを指定する。

## 新規作成・PoC

```text
guides/00_policy.md と guides/01_ai_coding_rules.md を前提に、次の目的を満たすツールを実装してください。

- 目的:
- 想定利用者・利用場面:
- 入力:
- 期待する出力:
- 必須要件:
- 案件固有の制約:
- 対象外:
- 参照する追加ガイド:

細かな実装手順は固定しません。目的と制約を満たす単純な方法を選び、調査から実装、確認、テスト、必要な文書更新まで完了してください。
```

## 既存ツール修正

```text
guides/00_policy.md と guides/01_ai_coding_rules.md を前提に、次の問題を修正してください。

- 対象:
- 現在の問題・再現手順:
- 期待する挙動:
- 案件固有の制約:
- 完了条件:

関連箇所を調査し、修正、回帰テスト、README等の整合確認まで実施してください。
```

## レビュー・総点検

```text
guides/00_policy.md、guides/01_ai_coding_rules.md と関連チェックリストを基準に総点検してください。

- 対象:
- 利用環境:
- 確認したい懸念:
- 完了条件:

通常業務への影響が大きい問題を優先し、再現した問題は可能な範囲で修正・テストしてください。問題が再現しなければ無理に変更せず、確認結果を記録してください。
```

## README・配布準備

```text
guides/06_readme_template.md と必要な配布ガイドを参照し、現在の実装と利用方法に文書を合わせてください。

- 対象ツール・版:
- 想定利用者:
- 配布方法:
- 今回の変更:

READMEへ更新履歴や非対応事項を網羅せず、利用判断に必要な現行情報だけを残してください。確認可能な配布・起動・テストを実施し、未確認事項は理由、リスク、次アクションを記録してください。
```

## プロンプト改善時の判断

同じ恒久条件を複数の案件プロンプトへ足したくなった場合は、まず既存ガイドとの重複を確認する。不足ならガイドを更新し、プロンプトには参照先と案件固有の差分だけを残す。
